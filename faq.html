MacPass can be extended with Plugins. Below is a list of all officially supported plugins. To install a plugin, either download the file with the supplied link or browse the plugin repository in MacPass.

What happened to macpassapp.org?

The short version – I fucked up and lost the domain.

The long version – The reminder emails from the hoster for the upcoming domain renewal did get lost in my SPAM folder. The domain did expire on June 13th 2026. I eventually found out about the deletion at the end of August. I immediately tried to undelete the domain but it failed due to being was past all grace periods. The domain was picked up by DropCatch. There was more than one potential buyer which lead to the domain entering into public auction. It was sold for $610 which was quite a bit larger than the amount I was able to throw at the problem.

The solution - move everthing to a new domain and hope for the best!

Are Versions 0.8.1 and earlier at risk?

No! MacPass only uses the domain for the plugin definition file. The contents of this JSON file get's displayed in the plugin repository browser.

Worst Case

A malicous entity hosts an altered plugins.json file on macpassapp.org. You will then see the pluings in the repsitory browser. If you then click the download button, MacPass will load the file and store it at ~/Libary/ApplicationSupport/MacPass. Since the plugin is not signed with the correct developer certificate, MacPass will refuse to load it unless you have enabled the option "Load unsecure Plugins".
