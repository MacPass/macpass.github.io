Below is a list of all frequently asked questions. Hopefully you'll find your answer. Feel free to contact me if you cannot find the answer you were looking for.

What happened to macpassapp.org?

The short version – I fucked up and lost the domain.

The long version – The reminder emails from the hoster for the upcoming domain renewal did get lost in my spam folder. The domain did expire on June 13th 2026. I eventually found out about the deletion at the end of August and immediately tried to undelete the domain. The attempt failed due to it being way past all grace periods. After the domain dropped it was picked up by DropCatch. To my knowledge there was more than one potential buyer which lead to the domain entering into public auction. There it was sold for $610 – quite a bit larger than the amount I was able to throw at the problem.

The solution - move everything to a new domain. Release an updated version of MacPass and hope for the best!

What should I do?

Please update to version 0.8.2 as soon as possible. The automatic updater will pick up the version and you should be set. If you have to use an older version of MacPass, go to the Plugin Settings and

  • Uncheck Download current Plugin information
  • Uncheck Load insecure Plugins

This might lead to MacPass informing you about incompatible plugins. MacPass ships with a plugin definition file but this might be out of date and lead to MacPass disabling some Plugins. You can re-enable them by

  • Check Force loading of incompatible Plugins
  • Keep Load insecure Plugins unchecked!

Are Versions earlier than 0.8.2 at risk?

No! MacPass only uses the domain for the plugin definition file. The contents of this JSON file get's displayed in the plugin repository browser. If you have not checked Plugin Settings → Download current Plugin information MacPass does not use the domain for any other connection and only relies on the built in plugin definition file

Worst Case

A malicous entity hosts an altered plugins.json file on macpassapp.org. You will then see the plugins in the repository browser. If you then click the download button, MacPass will load the file and store it at ~/Libary/ApplicationSupport/MacPass/. Since the plugin is not signed with the correct developer certificate, MacPass will refuse to load it unless you have enabled the option Load insecure Plugins.
